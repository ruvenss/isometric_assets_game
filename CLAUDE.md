# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Isometric game asset tiles for building maps (see `README.md`). Tiles are generated by zero-dependency Node scripts in `scripts/`; there is no build system or test suite.

## Structure

Assets are organized by art style first, then by setting:

```
STYLES/
  PIXEL/
    INDOORS/
    OUTDOORS/
  VOXEL/
    INDOORS/
    OUTDOORS/
```

New assets belong under the matching `STYLES/<STYLE>/...` folder. Keep folder names in uppercase so new folders match the existing ones. `STYLES/README.md` exists but is currently empty.

## Generating tiles

- `node scripts/office-pixel.mjs` regenerates the pixel office set (brief: `office.md`) into `STYLES/PIXEL/INDOORS/OFFICE/`: one PNG per tile in `FLOORS/`, `WALLS/`, `DECOR/`, `DOORS/`, `WINDOWS/`, `FURNITURE/` and `KITCHEN/` (voxel-rendered props), 1024x1024 sheets (`office_tileset*.png`, `office_decor_tileset.png`), the config `office_tileset.json` and `preview_*.png`.
- **Never overwrite an existing file** (rule in `office.md`). The generator skips any file that already exists, puts new designs on new sheets and only adds entries to `office_tileset.json`. To redraw a tile on purpose, delete its PNG and its config entry first. Do not edit the PNGs by hand. Since output is permanent, try new designs first with `OFFICE_OUT=<scratch copy> node scripts/office-pixel.mjs`.
- The contract for every tile (2:1 dimetric at 26.565°, 128x64 floor diamond, 128x256 canvas, anchor at the bottom vertex, light from upper-left, naming) is in `STYLES/PIXEL/INDOORS/OFFICE/TILE-SPEC.md`. New office tiles must follow it.
- Validate with the `isometric-ops` skill's `tile-validate.py`. The commands are in the spec.

- `node scripts/office-voxel.mjs` regenerates the voxel office set (brief: `STYLES/VOXEL/INDOORS/OFFICE/office.md`) into `STYLES/VOXEL/INDOORS/OFFICE/`, using the renderer in `scripts/voxel-engine.mjs` (rounded solids, ray-marched, soft shadows, worker threads; about a minute). Same folders and names as the pixel set, 256x128 tiles, 2500x2500 sheets, `office_tileset.json` and `preview_*`. Its contract is `STYLES/VOXEL/INDOORS/OFFICE/TILE-SPEC.md`. The same never-overwrite rule applies: sprites already in the config are skipped. Dry run with `OFFICE_OUT=<scratch dir>`; `OFFICE_ONLY=<regex>` renders a subset.
- New voxel sets for other places should reuse `scripts/voxel-engine.mjs`.

When new build scripts, tile specs or tooling are added, update this file to document them.
